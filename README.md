Интерактивный симулятор роста дерева, работающий прямо в браузере. Наблюдайте за развитием растения, переключайте сезоны и экспериментируйте с режимами автоматического роста или кликера.

## ✨ Возможности

- **Визуальный рост** — дерево поэтапно развивается от семени до взрослого растения.
- **Смена сезонов** — режимы «Лето» и «Осень» влияют на внешний вид.
- **Авто-режим** — дерево растёт самостоятельно, без участия пользователя.
- **Кликер** — интерактивный режим, где каждое нажатие ускоряет рост.
- **Лёгкость запуска** — не требует установки серверов или сборки, достаточно открыть HTML-файл.

## 🛠 Технологии

- **HTML5** — структура страниц (`index.html`, `grow.html`).
- **CSS3** — оформление и визуальные эффекты (`style.css`).
- **JavaScript** — логика симуляции, обработка кликов и таймеров (`index.js`).

## 🚀 Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Timothy3000/Tree-simulator.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Tree-simulator
   ```
3. Откройте файл `index.html` в любом современном браузере (двойным кликом или через `File → Open`).

> 💡 Для работы не нужен Python, Node.js или веб-сервер — это полностью статический проект.

## 🎮 Использование

- На главном экране нажмите **«Начать рост»**, чтобы запустить симуляцию.
- Переключайте сезоны кнопками **«Лето»** и **«Осень»**.
- Включите **«Авто»** для автоматического роста или **«Кликер»** для интерактивного режима.
- Кнопка **«Завершить рост»** останавливает симуляцию.
